# Daily Status Report Skill

Generate a concise daily engineering status report.

Always use this exact structure:

## Done

- List completed work

## Blockers

- List blockers
- If there are no blockers, write: None

## Next

- List the next tasks

Rules:

- Keep the tone professional and concise
- Do not invent information
- Use bullet points
- Keep each bullet short
